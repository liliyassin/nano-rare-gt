# Daily Routine: Mad Scientist Mode (7 Weeks)

**Rule:** Sleep is non-negotiable. 12 hours of focused work is only sustainable with 8 hours of sleep and one walk per day.

(if i want to see in nice table view cmd+shift+v)

---

## Schedule

| Time | Activity | Guardrails |
|------|----------|------------|
| **0600** | Wake, coffee, 30 min reading | Read only: Nature / Molecular Therapy / Human Gene Therapy / ASGCT newsletter. No social media. No email. |
| **0630** | **Deep Work Block 1 (3h)** | Hardest task of the day. No phone. No Slack. No email. If stuck, write pseudocode or outline prose; do not switch tasks. |
| **0930** | Break | Walk outside. 10 min minimum. No screens. |
| **1000** | **Deep Work Block 2 (3h)** | Second-hardest task. Continue if in flow; switch to next scheduled task if first is complete. |
| **1300** | Lunch + 30 min break | Eat away from desk if possible. No work reading. |
| **1400** | **Integration Block (2h)** | Testing, debugging, writing transitions between sections, assembling figures. Lighter cognitive load. |
| **1600** | Coffee + 30 min break | No screens. Stretch. |
| **1630** | **Integration Block 2 (2h)** | Continue integration, or switch to next day's prep if ahead of schedule. |
| **1830** | Dinner break | Completely off. Social or solitary, but no work. |
| **1930** | **Light Work Block (2h)** | Documentation, citations, reading, tests, figure formatting. No hard debugging. |
| **2130** | **Shutdown ritual (15-30 min)** | Git commit everything. Write 3 specific objectives for tomorrow. Clear desk. |
| **2200** | Hard stop | Sleep. |

---

## Weekly Rhythm

| Day | Focus |
|-----|-------|
| Monday | Hard architecture / new modules |
| Tuesday | Implementation / writing |
| Wednesday | Integration / validation |
| Thursday | Debugging / refinement |
| Friday | Polish / tests / documentation |
| Saturday | Case study work / reading / lighter writing |
| Sunday | Paper writing / figure making / preparation for next week |

There are no weekends off. But Saturday/Sunday are lighter cognitive load to prevent cumulative burnout.

---

## Commit Rules

1. **Commit every evening at 2130 minimum.** Even if messy. Commit message must start with week-day code: "w1d1", "w4d22", etc.
2. **Push to remote (GitHub) every 3 days.** Do not risk losing work to disk failure.
3. **Tag at end of every week:** `w1-complete`, `w2-complete`, etc.
4. **Tag at milestones:** `v0.1-PoC`, `v0.2-alpha`, `v1.0-submission`

---

## Environment Rules

- **One workspace only.** VS Code full-screen, terminal panel open, no other apps visible.
- **Phone:** in another room during deep work blocks. Use Forest app or screen-time lock if needed.
- **Email:** check once per day at 1930 during light work block. No exceptions.
- **Music:** instrumental only (classical, lo-fi, ambient). No lyrics.
- **Food:** prepare meals in advance twice per week. Do not waste decision-making energy on food during work hours.

---

## Energy Management

| Symptom | Action |
|---------|--------|
| Brain fog at 1000 | You did not sleep enough. Do 10 burpees or a cold shower. If persists, take 20 min nap. |
| Stuck on bug for >45 min | Write problem description in a new file, switch tasks for 1 hour, return with fresh eyes. |
| Writing sounds stupid | Read it aloud. If still bad, sleep on it. Never discard text; move to `paper/drafts/` for later mining. |
| No motivation | Re-read the Introduction draft. Remember the 6,000 diseases. You are the only one building this right now. |
| Headache | 20 min walk. Water. Screen brightness down. If chronic: schedule eye exam. |
| Loneliness | This is normal for deep work. Text one person at lunch. Do not sacrifice focus for social needs during blocks. |

---

## Sunday Evening Ritual (30 min)

Every Sunday at 2200:
1. Review week's git log. Are you on track?
2. Update PAPER_ARCHITECTURE.md with actual word counts per section.
3. Identify next week's highest-risk task (the one most likely to fail/slip).
4. Write one paragraph of "what I learned this week" in `docs/weeknotes.md`.
5. Sleep 30 min earlier than usual.

---

*This routine was designed for 49 consecutive days of high-output work. It is aggressive but physiologically sustainable if the rules are followed.*
